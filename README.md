# To-Do List App

A Flutter task list. Add non-empty tasks, mark them complete, dismiss them to delete, and see the remaining count in the app bar. Empty and all-complete states are handled explicitly.

## Run in DartPad

Open [DartPad](https://dartpad.dev/), choose Flutter, paste `lib/main.dart`, then select **Run**.

## Run locally

Install Flutter, then run `flutter pub get` and `flutter run` from this folder.

## Checklist walkthrough

Add five items, complete two, dismiss one, and confirm the remaining counter updates. Try adding whitespace only; it is ignored. Dismiss every item to see the empty state.
